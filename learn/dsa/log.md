# Nhật ký DSA

Ghi **ngay sau mỗi bài**, đừng để dồn cuối tuần — chi tiết "sai ở đâu" bay mất rất nhanh.

Cột quan trọng nhất là **Sai ở đâu**. Cuối mỗi tháng đọc lại toàn cột đó: bạn sẽ thấy mình
sai lặp đúng 3-4 kiểu (off-by-one, quên case rỗng, chọn nhầm cấu trúc dữ liệu…).
Đó mới là thứ cần luyện — không phải làm thêm bài mới.

Ký hiệu cột **Tự lực**: `T` tự làm được · `G` phải xin gợi ý · `L` phải xem lời giải.
Bài `G` hoặc `L` → hẹn làm lại sau 7 ngày, điền cột **Làm lại**.

| Ngày | Chủ đề | Bài | Ngôn ngữ | Phút | Độ phức tạp (time / space) | Tự lực | Sai ở đâu | Làm lại |
|---|---|---|---|---|---|---|---|---|
| | | | | | | | | |
